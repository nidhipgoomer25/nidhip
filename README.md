# ⚡ RandomVerse

> An interactive procedural cyber playground featuring real-time particle dynamics, Web Audio API synthesizers, color palette alchemy, cyber reflex trials, and identity forge generators.

## 🌟 Features

- **Quantum Particle Canvas Swarm**: Dynamic kinetic physics system that responds to cursor coordinates, mouse attraction/repulsion, and supernova shockwaves.
- **Neon Surge Reflex Mini-Game**: Fast-paced cyber target arcade test with high score persistence (`localStorage`), combo sounds, and visual rings.
- **Synthesizer SFX Studio**: 100% procedural Web Audio API sounds (Laser zap, sub-bass, arpeggios, warp drive, powerups, chiptune glitches).
- **Color Palette Alchemy**: Procedural harmonic color generator with one-click HEX copying and CSS gradient exports.
- **Cyber Identity Forge**: Procedural character generator with dynamic stat bars, lore tags, and netrunner classifications.
- **Cosmic Oracle & Daily Quests**: Seeded wisdom generator and micro-quest challenge board.
- **Atmosphere Switcher**: One-click theme switcher cycling between *Cyberpunk Neon*, *Synthwave Sunset*, *Emerald Matrix*, and *Solar Flare*.
- **Zero Dependencies**: Pure HTML5, CSS3, and ES6 JavaScript. Instant <50ms load time.

## 🚀 Running Locally

Simply open `index.html` in any modern web browser:

```bash
# Using python 3
python3 -m http.server 8080

# Or with npx serve
npx serve .
```

## 🌐 Deploying to GitHub Pages

This repository comes pre-configured with a `.github/workflows/deploy.yml` GitHub Actions workflow.
Once pushed to GitHub:
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment**, set Source to **GitHub Actions**.
3. Every push to `main` automatically deploys the live website!
